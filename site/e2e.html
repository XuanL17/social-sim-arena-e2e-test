Run it again

Run this in the local test repository. It only triggers the platform entry point; the signed request, the answer parsing and the scoring all happen server-side on Vercel.

.local/venv/bin/python tools/trigger_hosted_e2e.py

The operator token lives in an ignored local directory and never needs to be pasted into a page. A successful report is saved as site/e2e-results.json and appears here after the platform is redeployed.

The test uses fixed synthetic questions with simulated deadlines and release times. Automatic refresh stays off, and the historical snapshot kept on the original site is not this test’s result.
